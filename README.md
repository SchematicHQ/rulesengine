# rulesengine

> **Deprecated.** This repository is no longer maintained and will be archived again.
>
> It is kept public only so that builds of [schematic-go](https://github.com/schematichq/schematic-go) **v1.5.4 and earlier** that fetch modules directly from GitHub keep working. schematic-go v1.5.5 and later no longer depend on this module; upgrade to a current release of schematic-go and drop any direct dependency on `github.com/schematichq/rulesengine`.
>
> No new versions will be published and no issues or pull requests will be accepted.

Go implementation of the Schematic rules engine, previously used by the Schematic Go SDK for flag evaluation.
